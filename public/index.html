Set up your keys to start testing

This console calls the real Payzaapi API on your behalf. Give it your test keys once, and every request below is signed for you.

  1. Create an account at payzaapi.co.ke and get your pk_test_ / sk_test_ keys.
  2. Paste them into Settings, along with your webhook signing secret.
  3. Copy the callback URL shown there into any payment you create — it's this console, ready to log deliveries.
  4. Fire a test pay-in from the Pay in tab and watch it arrive below.

Go-live checklist

  • Verify X-Payza-Signature on every webhook (this console does it for you).
  • Reply 200 within 10 seconds and ignore events you've already processed.
  • Fulfil orders from the webhook or verify, never the redirect alone.
  • Check amount and currency against the order before fulfilling.
  • Use a unique reference for every payment.
  • Swap in pk_live_ / sk_live_ keys when you're ready.
